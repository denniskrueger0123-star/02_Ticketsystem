API-Keys für die KI-Anbieter hinterlegen, damit „✨ Prompt generieren" funktioniert.

Trage hier deinen API-Key für einen oder mehrere Anbieter ein. Die Keys werden ausschließlich serverseitig gespeichert (als Datei im Projektordner) und niemals an den Browser zurückgegeben oder in Git eingecheckt.

Automatisches Backup

Sichert jedes Projekt als eigene Datei im Export-Format – automatisch nach Änderungen (gebündelt, höchstens einmal pro Minute) und zusätzlich im eingestellten Intervall. Wiederherstellen über „Projekt importieren“ auf der Startseite. Intervall, Ordner und Anzahl werden über .env bzw. Umgebungsvariablen eingestellt (BACKUP_INTERVAL, BACKUP_DIR, BACKUP_KEEP).

Datenintegrität

Prüft alle Projekt- und Ticket-Dateien auf Schäden: unlesbare Dateien, falsche Zuordnungen, ungültige oder abweichend geschriebene Werte, doppelte Ticketnummern, fehlende Felder. Reparierbare Befunde lassen sich mit einem Klick beheben – vorher wird automatisch ein Backup erstellt. Unlesbare Dateien werden nicht gelöscht, sondern nach data/quarantaene/ verschoben.

System-Anweisungen

Diese Grund-Anweisungen steuern, wie die KI arbeitet. Du kannst sie anpassen; „Auf Standard zurücksetzen“ stellt den Originaltext wieder her.

Wo bekomme ich einen API-Key her?

  • Claude (Anthropic): console.anthropic.com → API Keys → Create Key
  • Google Gemini: aistudio.google.com/app/apikeys → Create API Key (kostenloser Tarif verfügbar)
  • OpenAI (ChatGPT): platform.openai.com/account/api-keys → Create new secret key
  • Firmen-LLM (LiteLLM-Proxy): kein öffentlicher Key – frag deinen Arbeitgeber/Admin nach der Basis-URL eures Proxys und deinem persönlichen (virtuellen) Key. Beides unten bei „Firmen-LLM" eintragen; bei „Modell" die vom Admin freigegebene Modell-ID (z. B. gpt-4o) hinterlegen.

Wichtig: Ein ChatGPT-Plus- oder Gemini-Abo ist nicht dasselbe wie ein API-Key – du brauchst den separaten Key aus dem jeweiligen Entwickler-Portal oben.

Modelle abrufen oder selbst eintragen

Mit „🔄 Modelle abrufen" fragst du die aktuell verfügbaren Modelle direkt beim Anbieter ab (dein Key bleibt dabei auf dem Server). Die Liste wird gespeichert und steht danach im „KI-Modell"-Dropdown zur Verfügung – auch nach einem Neustart, ohne erneuten Abruf.

Anbieter benennen ihre Modelle immer wieder um (z. B. wird aus einem Flash-Modell eine neuere Version). Trage darum pro Anbieter im Feld „Modell" die aktuelle Modell-ID ein (z. B. gemini-3.6-flash). Sie erscheint dann im „KI-Modell"-Dropdown im Projekt und wird für die Generierung verwendet. Die vorgegebenen Modelle bleiben zusätzlich wählbar. Die genaue Modell-ID findest du in der Doku des jeweiligen Anbieters.
