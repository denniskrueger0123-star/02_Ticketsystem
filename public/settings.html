API-Keys für die KI-Anbieter hinterlegen, damit „✨ Prompt generieren" funktioniert.

Trage hier deinen API-Key für einen oder mehrere Anbieter ein. Die Keys werden ausschließlich serverseitig gespeichert (als Datei im Projektordner) und niemals an den Browser zurückgegeben oder in Git eingecheckt.

Wo bekomme ich einen API-Key her?

  • Claude (Anthropic): console.anthropic.com → API Keys → Create Key
  • Google Gemini: aistudio.google.com/app/apikeys → Create API Key (kostenloser Tarif verfügbar)
  • OpenAI (ChatGPT): platform.openai.com/account/api-keys → Create new secret key

Wichtig: Ein ChatGPT-Plus- oder Gemini-Abo ist nicht dasselbe wie ein API-Key – du brauchst den separaten Key aus dem jeweiligen Entwickler-Portal oben.
